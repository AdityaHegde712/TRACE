\section{Limitations}
\label{sec:limits}

\begin{enumerate}
  \item \textbf{The decision rule shows no advantage from dependence
        awareness.} We ran the calibrated tolerance sweep. The single-source
        test decides 97.4\% of tasks before the risk estimate is used, so the
        tolerance moves the verification rate by only 2.6 points. At equal
        verification cost the rule closes no fewer unsafe tasks than random
        choice among the tasks it could close. The estimator is also fitted
        per detector pairing, not per task. A finer estimator, for example
        one keyed on illumination or object size, is untested. A rule that
        verifies every task also reaches zero false clearance.
  \item \textbf{Scope.} One town (Town10HD), vehicle objects, one frame per
        scene, two cameras, simulation only.
  \item \textbf{Detectors overlap in training data.} Both are COCO-pretrained,
        so the mixed pairing is not an independently trained pair.
  \item \textbf{The ratio depends on marginal accuracy.} Ratios are not
        comparable across detectors as measures of coupling.
  \item \textbf{Association is unvalidated against truth.} Ground-projection
        matching has no measured accuracy, and a vehicle seen from opposite
        sides can project metres apart.
\end{enumerate}
