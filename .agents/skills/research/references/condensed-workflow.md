# Condensed Research Workflow

Use for quick lookups while building: how a library works, what a term means, which tool to pick. Results are working notes, not evidence for the proposal or report.

1. **Retrieve, do not recall.** Search or open the official documentation or the original paper. Do not answer from memory alone.
2. **Prefer authoritative, recent sources:** official docs, standards, peer-reviewed papers, the library's own repository. Skip SEO articles and unattributed summaries. Prefer sources from the last 2 years; say so when using an older one.
3. **Cite every claim** with title, publisher or author, date, and URL.
4. **Quote exactly** when quoting. Never reword inside quotation marks.
5. **Separate fact from guess.** Mark each statement as "source says" or "my inference".
6. **State doubts.** Say what you could not verify and where sources disagree. Do not smooth over conflicts.
7. **Label the result** at the top: "Quick lookup, not verified for the report."
8. **Escalate.** If the answer will be used in the proposal, the report, a novelty claim, or an advisor discussion, stop and tell the user to switch to `references/full-pipeline.md` and involve Aditya.

Write findings in plain English; define any term the user may not know.
